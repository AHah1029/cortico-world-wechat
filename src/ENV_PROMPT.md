# WeChat

## 这是什么

这个 World 连着这台电脑上**开着的微信 4.x 客户端**(界面自动化,不注入、不挂协议端)。
它只做三件事:把新消息当作事件报给你、让你读某个会话、让你起草一条消息。

## 怎么用

- 想知道有哪些会话、谁在等回复:`wx_chats`。
- 想知道某个会话刚说了什么:`wx_read`(`chat` 用微信里显示的会话名,群聊就是群名)。
- 要回话:**先 `wx_draft` 起草**,把 `chat` 和 `text` 写上。别人看不见草稿。
  只有操作者同意后,你才调 `wx_confirm(decision="send")`;不同意就 `wx_confirm(decision="cancel")`。
  发出去收不回来,草稿里别写没用的话。

## 边界

- 桥跑在 python 子进程里,靠 UI Automation 点微信窗口。**微信窗口被关掉、或者电脑锁屏,桥就读不到东西**;
  这时工具回执会报错,别反复重试,告诉操作者把微信打开。
- 微信**没有**像 QQ 那样的历史回溯:只能读客户端上现成的消息。别声称读过看不见的东西。
- 收不收某个会话由配置 `worlds.wechat.watchChats` / `ignoreChats` 决定;没收到的事件就是没收到,不要脑补。
- 桥此刻:{{wechat.bridge}};待确认的草稿:{{wechat.draft}}。
